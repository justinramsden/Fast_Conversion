# Fast Conversion

A measurement converter built for the fewest taps: type a number, tap a unit, read the answer.

Open it on a phone and use **Add to Home Screen** (iPhone: Share menu; Android: Chrome's ⋮ menu) to install it. It works offline after the first visit.

- mm / cm to inches (decimal and fraction), feet, and feet-and-inches
- °C / °F, km / mi, kg / lb and the rest of the everyday units
- Its own number keypad on phones and tablets: open the app and type, no tap on the box first. The `abc` key brings up the phone's keyboard for letters and dictation.
- Tap any answer to copy it
- Real-size ruler along the edges, with the typed length marked
- Customize it with any AI chat: tap **Copy AI instructions**, ask for what you want (units, answers, the keypad's order, look and colours), then tap **Paste AI answer**. The guide the AI follows is [CUSTOMIZE.md](CUSTOMIZE.md).
