    Click a value to copy it. Click a unit to switch to it.

    Ways to type a value

    A bare number reads as the last unit you used.
    Put the unit after the number. The space is optional.
    A fraction with no unit reads as inches.
    Feet and inches. 5ft 7in works too.
    f, c and k are the temperatures.
    Name a target to put it on top. Typing "to" works as well.
    A unit alone shows what one of it is.

    Keys

    Enter copies the marked value. Shift+Enter copies it with its unit.

    ↑ ↓ move the mark to another row. It stays there while you type new numbers.

    Esc clears the box. After a copy, typing a number replaces the value and typing a unit swaps only the unit.

    Start typing from anywhere on the page and it lands in the box.
